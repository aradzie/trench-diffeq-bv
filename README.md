# Elementary Differential Equations with Boundary Value Problems

This work is derived from _Elementary Differential Equations with Boundary
Value Problems_ by William F. Trench. The visual style has been adapted to our
liking, and the text has been corrected where needed; the content is otherwise
the original author's. The original TeX source files are available at
<https://digitalcommons.trinity.edu/mono/9/>.

## Proofreading

The book has been proofread with the help of AI. The corrections include fixes
to the prose, to mathematical errors in the text, theorems and examples, and to
the answers to the exercises. Every correction is recorded, section by section,
in the proofreading ledger [`PROOFREADING.yaml`](PROOFREADING.yaml).

## Download

The PDFs are built from this repository on every push to `master` and
published at <https://aradzie.github.io/trench-diffeq-bv/>:

- [The full book](https://aradzie.github.io/trench-diffeq-bv/TRENCH_DIFFEQ_BV.pdf)
- [All theorems](https://aradzie.github.io/trench-diffeq-bv/theorems.pdf)
- [All examples](https://aradzie.github.io/trench-diffeq-bv/examples.pdf)
- Individual chapters, from
  [Chapter 1](https://aradzie.github.io/trench-diffeq-bv/chapters/01.pdf) to
